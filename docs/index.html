Music and lyrics, on your taskbar.

kRon is a small pill next to your system tray. It shows what’s playing, with synced lyrics, and opens a panel when you hover it.

No lyrics? Find them, or write your own.

  1. kRon looks in your own files, then in what it saved, then on LRCLIB.
  2. Nothing yet? Press the magnifier in the panel. It searches LRCLIB and QQ Music, and you pick the version that fits.
  3. Still nothing? Press + and write them yourself. Put a time before each line, save, and kRon sings along.

Try it. Neither song here has lyrics yet. Press Search on the desktop, or the magnifier in the panel, and pick a result. Then press next for the second song, which no search can find, and press + to write your own.

Good to know

Does it work with Spotify?
Yes. kRon reads Windows media controls, so Spotify, Apple Music, browsers and Media Player all show up.
Is it free?
Yes. It is open source under the MIT license.
Which Windows versions?
Windows 10 and Windows 11.
Where do lyrics come from?
Your own .lrc files first, then lyrics kRon already saved, then LRCLIB, a free open database of synced lyrics.
Why does Windows warn me?
Releases aren’t code-signed yet, so Windows and some antivirus tools treat the installer as unknown. We are applying for free signing.
Does it track me?
No accounts, no analytics, no telemetry. The privacy section says exactly when it goes online.

Code signing policy

We are applying for free code signing for open-source projects from SignPath Foundation, with signing performed by SignPath.io. Until the first signed release is published, installers are unsigned. This section will be updated when that happens.

  • Releases are built from the public source by GitHub Actions in arontz/kRon, then signed. Nothing is built or signed by hand.
  • The signing request is made by the release workflow when a version tag is pushed.
  • Maintainer, reviewer and approver: arontz.
  • Only the installer is signed at first. The installed app and the uninstaller are not yet.

Privacy

kRon has no accounts, no analytics and no telemetry. What you play, your settings and the lyrics it saves stay on your PC. It only talks to the internet in these cases:

  • Finding lyrics: when a song starts and no lyrics are saved, it asks LRCLIB for them, sending the song’s title, artist, album and length.
  • Search for lyrics: only when you use it, it sends your search text to LRCLIB and to QQ Music.
  • Check for updates: only when you click it in the tray menu, it asks the GitHub API for the latest release.

The demo on this page is kRon’s own interface running on sample songs, numbers and search results (all made up). It plays no audio. The only thing this page fetches is the download count, from the public GitHub API.
